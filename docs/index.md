# syseng-toolkit

Free systems engineering templates for small hardware teams, in spreadsheets that work the same in Google Sheets and in Excel.

They were built for robotics projects with a handful of engineers: enough structure to stop the mistakes that cost weeks (a requirement nobody can test, a part nobody ordered, a task with no owner), without a requirements database or a project management system to learn.

## The templates

| Template | What it's for | Version |
|---|---|---|
| [Document List](templates/document-list.md) | The register of every project document: ID, where it lives, a link. Start here. | 1.0.0 |
| [Requirements](templates/requirements.md) | What the system must do, how each requirement flows down, and how it will be verified. | 1.0.0 |

More templates are on the way: a Task Tracker, a Bill of Materials, a Trade Matrix and a Risk Register.

## What every template has

- **Typed columns are white, calculated columns are gray.** Formulas are filled in ahead, so you only ever type in white cells.
- **A note on every column header.** Hover over a header to see what goes in the column.
- **A README tab** that explains the tabs and the rules, and links back here.
- **IDs that are never reused** (`D-###`, `REQ-###`), so a reference written down today still means the same thing next year.
- **Release notes inside the file.** The `Template History` tab says which version your copy is, and what changed in each release.
